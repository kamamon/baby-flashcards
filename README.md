# ベビー フラッシュカード

赤ちゃん向けの写真フラッシュカード（実写・白い背景・日本向け）。

- 写真のカード 215枚（どうぶつ・たべもの・のりもの・みのまわり・はな・しぜん・にっぽんのもの・がっき）、国旗 42枚、いろ・かたち、ドットカード
- あいうえお（ひらがな・カタカナ）：めくって カード（字をタップすると写真が出る）・ふうせん クイズ・なぞって かこう（「OK」で判定）・カード あわせ（字と写真の神経衰弱）・ひょっこり タッチ（もぐらたたき風）・ことば つくり（字を並べて言葉に）
- あそぶと コインが たまり、ガチャガチャで シールが もらえます（シールちょうに あつまります）
- ✨ スペシャル シール：おうちで撮った写真（おもちゃ・ぬいぐるみ・絵本など）を、その端末の中だけでガチャの金色カプセルのシールにできます。写真は端末内（IndexedDB）にだけ保存され、サーバーには送られません
- いちど開くと写真がぜんぶ保存され、オフラインでも使えます
- 写真の撮影者とライセンスは [CREDITS.txt](CREDITS.txt) とアプリ内の「しゃしんの クレジット」にあります（あいうえおの文字は Klee One・[OFL](OFL-KleeOne.txt)）

アプリ：https://kamamon.github.io/baby-flashcards/
